### CareBook – UX Design Rationale

## Project Overview

CareBook is a mobile appointment booking application designed to make scheduling healthcare appointments simple and convenient.

## UX Flow

The application follows a simple five-screen journey:

1. Welcome Screen – Introduces the CareBook application.
2. Login Screen – Allows users to access their account.
3. Specialist Selection – Helps users choose the required medical specialist.
4. Date & Time Booking – Allows users to select their preferred appointment date and time.
5. Appointment Confirmation – Displays the booking confirmation and appointment details.

## Design Decisions

- Used a consistent lavender and purple colour palette.
- Used clear headings and readable typography.
- Designed simple buttons and input fields.
- Used specialist cards to make selection easier.
- Highlighted the selected date and time.
- Provided a confirmation screen to reassure users that their booking is complete.

## Usability Goals

The design focuses on easy navigation, fewer steps, clear information and a user-friendly mobile experience.

## Tools Used

- Figma – UI design and prototyping
- GitHub – Project documentation and submission

## Conclusion

CareBook demonstrates a simple and convenient mobile appointment booking experience with a clear user journey from login to booking confirmation.
